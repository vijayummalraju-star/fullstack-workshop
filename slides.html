Express.js — Hello World

const express = require('express');
const app = express();

app.get('/api/hello', (req, res) => {
  res.json({ message: 'Hello from the backend! 🎉' });
});

app.listen(3000, () => console.log('Server running!'));

That's a working server in 7 lines of code!

Live Demo Time!

Let's build a To-Do app from scratch

Express.js + HTML/CSS/JS → Full Stack App

What Just Happened?

When you clicked "Add Task":

  • Frontend sends POST /api/tasks with { title: "Study" }
  • Backend receives the request & validates data
  • Backend stores it in the database (array)
  • Backend sends back { id: 1, title: "Study" }
  • Frontend receives response & updates the UI

Open DevTools → Network tab to see it live! 🔍
